# 04 – Networking Basics

## What is a Network
A network is a collection of computers and devices connected 
together to share data and resources with each other.

---

## Types of Network by Size
- **PAN (Personal Area Network)** — Smallest network, covers personal devices like phone and laptop. Example: Bluetooth
- **LAN (Local Area Network)** — Covers a small area like home, office or school
- **WLAN (Wireless LAN)** — Same as LAN but wireless. Example: WiFi
- **CAN (Campus Area Network)** — Covers a university or large campus
- **MAN (Metropolitan Area Network)** — Covers an entire city
- **WAN (Wide Area Network)** — Largest network, covers countries. Example: Internet

---

## Network Architecture
- **Peer to Peer** — Every device is equal, directly connected to each other. No central server
- **Client to Server** — Clients request data, server provides it. Most common in organizations

---

## Communication Modes
- **Simplex** — One way communication only. Example: TV broadcast
- **Half Duplex** — Two way but not at same time. Example: Walkie Talkie
- **Full Duplex** — Two way simultaneously. Example: Phone call

---

## Network Transmission Types
- **Unicast** — One sender, one receiver
- **Multicast** — One sender, multiple specific receivers
- **Broadcast** — One sender, all devices on network receive it
