# DNS in Detail

## What This Room Is About
This room explains how the Domain Name System (DNS) works
and why it is essential for internet communication.

## Key Things I Learned
- DNS helps us communicate with websites using names instead of IP addresses
- Instead of remembering IPs like 142.250.180.46 we just type google.com
- IP addresses are sets of numbers ranging from 0 to 255
- DNS acts as a translator between humans and digital systems

## DNS Record Types
- **A Record** — Points a domain to its IP address
- **CNAME Record** — Converts one domain to another domain
- **MX Record** — Tells where emails are going for a domain
- **TXT Record** — Stores extra information about a domain

## TLD Types
- **gTLD** — Generic TLD, shows the purpose (.com, .org, .edu)
- **ccTLD** — Country Code TLD, shows the country (.in, .uk, .us)

## How This Connects to Real SOC Work
DNS records are used daily in SOC investigations —
checking suspicious domains, tracing phishing emails,
and identifying malicious redirects.
