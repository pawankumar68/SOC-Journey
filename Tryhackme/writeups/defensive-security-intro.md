## Task 1 — Think Like a Defender
Unlike offensive security, defenders do not attack systems.
Instead they:
- Monitor systems 24/7
- Investigate suspicious activities
- Find and stop attacks before any damage occurs

This is the core mindset of a SOC Analyst — proactive defense!

## Task 2 — Detect Suspicious Activity
Accessed a monitoring dashboard — similar to a real SIEM.
A suspicious activity appeared on the dashboard.
Task was to identify and copy the suspicious IP address
for further investigation.

## Task 3 — Identify the Attack
Investigated the suspicious IP address from the dashboard.
- Found the source IP of the attacker
- Checked what the attacker was trying to access
- Identified **URL Discovery Attempts** — attacker was trying
  to find hidden pages on the website (directory brute forcing)

## Task 4 — Stop the Attack
Blocked the malicious IP address in the firewall.
This prevented the attacker from continuing the attack
and protected the system from further damage.

## How This Connects to Real SOC Work
This room simulates the exact workflow of an L1 SOC Analyst:
1. Monitor dashboard for alerts
2. Detect suspicious activity
3. Investigate the source and intent
4. Take action — block the threat
5. Document the incident

> 💡 This is the daily job of a SOC Analyst — detect, investigate, respond!
